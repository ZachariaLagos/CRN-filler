# NU CRN Filler 测试工具

只读测试工具，用来在 Banner 页面（包括 Plan Ahead）上检查：

- 正式插件需要的输入框和按钮是否存在
- 插件能否读到汇总面板（Summary）里的课程和状态
- 页面提示栏、声音和桌面通知是否正常
- 在 Plan Ahead 里自动点击 Add，把课程加入计划，检查点击和读取结果的流程

「添加到计划」只在 Plan Ahead 页面运行，不会点 Save Plan，也不会注册任何课程。

## 安装
1. 解压，打开 chrome://extensions
2. 确认开发者模式已开启，点「加载已解压的扩展程序」，选择 nu-test-kit 文件夹
3. 从拼图图标里固定它（深色图标，和正式插件分开）

## 使用
1. 打开 Plan Ahead 页面，刷新一次
2. 点测试工具图标，填入计划里已有的课程名、课程代码或 CRN（可选），点「扫描页面」
3. 点「测试提醒」，检查提示栏、声音和通知
4. 在 Find Classes 搜索一门课，在「添加到计划」里填课程名或 CRN，点「添加到计划」
5. 点「复制报告」，把报告发给需要帮你检查的人

## 按顺序添加并保存（模拟正式插件的选课逻辑）
1. 在弹窗里确认 Subject（Computer Science）和 College（Khoury College）
2. 按优先顺序填课程名，每行一个；「需要添加几门」填 2
3. 点「按顺序添加并保存」

它会展开 Advanced Search、选好 Subject 和 College、搜索，然后翻完所有结果页，
按顺序找课：找到就选，找不到就看下一个，选够就停。选够后点 Add Course，
最后点 Save Plan。如果 Banner 弹出计划名称框，请手动填写。
